## 接线表

### CH340 串口 (USART1 重映射)

| CH340 引脚 | 方向 | STM32 引脚 | 功能 |
|-----------|:---:|-----------|------|
| TX | → | **PB7** | USART1_RX (重映射后) |
| RX | ← | **PB6** | USART1_TX (重映射后) |
| GND | ↔ | GND | 共地 |
| 3.3V | → | — | 仅给 CH340 供电, 不给 STM32 |

### RGB LED (TIM2 PWM 三通道)

| LED 引脚 | STM32 引脚 | 定时器通道 |
|----------|-----------|-----------|
| R (红) | **PA0** | TIM2_CH1 |
| G (绿) | **PA1** | TIM2_CH2 |
| B (蓝) | **PA2** | TIM2_CH3 |
| GND | GND | — |

> PWM 参数: 72MHz / 72 = 1MHz → ARR=999 → 1kHz  
> 共阴驱动, 0~255 亮度映射到 0~999 占空比

### 板载 LED (诊断用)

| STM32 引脚 | 说明 |
|-----------|------|
| **PC13** | 低有效, 上电自测 + CMD 帧诊断 |

### SWD 调试口 (烧录/调试)

| STM32 引脚 | 功能 |
|-----------|------|
| PA13 | SWDIO |
| PA14 | SWCLK |
| GND | GND |
| 3.3V | VDD |

## 引脚功能表

| 引脚 | 功能 | 代码配置 | 说明 |
|------|------|---------|------|
| PA0 | R LED | TIM2_CH1, AF_PP | PWM 红灯 |
| PA1 | G LED | TIM2_CH2, AF_PP | PWM 绿灯 |
| PA2 | B LED | TIM2_CH3, AF_PP | PWM 蓝灯 |
| PB6 | USART1_TX | AF_PP, 重映射 | → CH340 RX |
| PB7 | USART1_RX | IN_FLOATING, 重映射 | ← CH340 TX |
| PC13 | 诊断 LED | Out_PP | 低有效 |
| PA13 | SWDIO | (调试器占用) | 烧录调试 |
| PA14 | SWCLK | (调试器占用) | 烧录调试 |

## 关键配置

| 参数 | 值 |
|------|-----|
| 重映射 | `GPIO_Remap_USART1` → PB6/PB7 |
| 波特率 | 9600 bps, 8N1 |
| 供电 | STM32 独立供电 (CH340 仅通信用, 不供电) |
