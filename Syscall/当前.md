# STM32F103 用户态/内核态分离实现记录

## 概述

在 STM32F103（Cortex-M3）上通过 **SVC（Supervisor Call）** 指令实现用户态（Unprivileged Thread Mode）与内核态（Privileged Handler Mode）的隔离。用户态无权直接访问外设寄存器，所有硬件操作必须通过 SVC 提权进入内核态执行。

## 核心技术机制

### 1. 模式与特权级

Cortex-M3 有两个独立维度：

| 维度 | 选项 | 本项目使用 |
|------|------|-----------|
| 运行模式 | Thread / Handler | Thread = 用户态，Handler = 内核态 |
| 访问等级 | Privileged / Unprivileged | 用户态 = Unprivileged，内核态 = Privileged |

### 2. CONTROL 寄存器

`__set_CONTROL(0x3)` 同时设置：
- bit[0] (nPRIV) = 1 → Unprivileged，无权访问外设寄存器
- bit[1] (ASP) = 1 → 使用 PSP（进程栈指针），与内核 MSP 隔离

### 3. SVC 指令

用户态执行 `SVC #N` 时，硬件自动：
1. 压栈 R0-R3, R12, LR, PC, xPSR 到当前栈（PSP）
2. 切换到 Handler Mode（永远是 Privileged）
3. 跳转到 `SVC_Handler`

### 4. 参数传递

- 用户态宏将参数放入 R0/R1，执行 SVC 指令
- `SVC_Handler` 汇编代码取 PSP 指针传给 `SVC_Router`
- `SVC_Router` 从栈帧 `pStackFrame[0]` / `pStackFrame[1]` 提取 R0/R1
- 调用对应的 `Kernel_*` 函数执行硬件操作

## 当前实现的 SVC 调用

| 调用号 | 宏 | 参数 | 内核函数 | 功能 |
|--------|-----|------|----------|------|
| 0x01 | `sys_GPIO_Set(port, pin)` | R0=端口, R1=引脚 | `Kernel_GPIO_Set` | 写 BSRR 寄存器置位 |
| 0x02 | `sys_GPIO_Reset(port, pin)` | R0=端口, R1=引脚 | `Kernel_GPIO_Reset` | 写 BRR 寄存器复位 |
| 0x03 | `sys_DelayMs(ms)` | R0=毫秒数 | `Kernel_DelayMs` | 阻塞延时 |

## main.c 执行流程

```
上电 → Privileged Thread Mode
 │
 ├─ 阶段 1: 初始化 GPIO (特权态, 可操作 RCC/GPIO 寄存器)
 │
 ├─ 阶段 2: SwitchToUserMode() —— 切入 Unprivileged Thread Mode
 │    此后直接操作硬件寄存器 → HardFault
 │
 └─ 阶段 3: while(1) 主循环
       sys_GPIO_Reset(GPIOC, PIN13)  → SVC #0x01 → 内核亮灯
       sys_DelayMs(500)              → SVC #0x03 → 内核延时
       sys_GPIO_Set(GPIOC, PIN13)    → SVC #0x02 → 内核灭灯
       sys_DelayMs(500)              → SVC #0x03 → 内核延时
```
